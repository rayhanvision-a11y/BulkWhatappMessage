# Standalone WhatsApp Web Management System

এটি একটি সম্পূর্ণ স্বাধীন (Standalone) WhatsApp ম্যানেজমেন্ট সিস্টেম। এটি লারাভেল বা পিএইচপির ওপর নির্ভরশীল নয়। সরাসরি Node.js দিয়ে চলে।

## ফিচারসমূহ:
- 📱 WhatsApp Web মাল্টি-সেশন কানেকশন (QR কোড স্ক্যান করে লগইন)
- 💬 সরাসরি চ্যাট লিস্ট, কন্টাক্ট ও মেসেজ সিনক্রোনাইজেশন
- 📤 একক বা বাল্ক মেসেজ / ছবি সেন্ডিং
- 📢 ব্রডকাস্ট মেসেজিং (শিডিউল্ড ও ইনস্ট্যান্ট)
- 📝 মেসেজ টেমপ্লেট ও সেভড কন্টাক্ট লিস্ট

## 🚀 পোর্টেবল উইন্ডোজ অ্যাপ হিসেবে চালানো (No Node.js Required):

এই ফোল্ডারে বিল্ট-ইন **Node.js (`bin/node.exe`)** সংযুক্ত করা আছে। তাই অন্য কারও কম্পিউটারে আলাদা করে Node.js ইন্সটল করার কোনো প্রয়োজন নেই!

1. **অ্যাপ চালু করতে:**
   - **`WhatsApp-Portal.vbs`** অথবা **`WhatsApp-Portal.bat`** ফাইলে ডাবল ক্লিক করুন।
   - কোনো কালো কমান্ড প্রম্পট উইন্ডো আসবে না; একদম ডেস্কটপ অ্যাপের মতো নিজস্ব ফ্রেমে চালু হয়ে যাবে।

2. **ডেস্কটপ শর্টকাট তৈরি করতে:**
   - **`Create-Desktop-Shortcut.bat`** ফাইলে একবার ডাবল ক্লিক করুন।
   - আপনার ডেস্কটপে **"WhatsApp Portal"** নামে একটি শর্টকাট আইকন তৈরি হয়ে যাবে।

3. **সার্ভার বন্ধ করতে:**
   - কাজ শেষ হলে **`Stop-Server.bat`** ফাইলে ডাবল ক্লিক করলেই ব্যাকগ্রাউন্ডের ব্যাকএন্ড সার্ভার বন্ধ হয়ে যাবে।

## 👥 অন্যদের সাথে শেয়ার / ব্যাকআপ করার নিয়ম:
- সহজে ফাইল শেয়ার করার জন্য **`Export-Project-Zip.bat`** ফাইলে ডাবল ক্লিক করুন।
- এটি স্বয়ংক্রিয়ভাবে অপ্রয়োজনীয় `node_modules`, আপনার ব্যক্তিগত `auth_info_*` লগইন ক্রেডেনশিয়াল এবং লগ ফাইল বাদ দিয়ে একটি ফ্রেশ ও ক্লিন `whatsapp-system.zip` ফাইল বানিয়ে দেবে।
- অন্য কেউ জিপটি আনজিপ করে সরাসরি চালাতে পারবে।
